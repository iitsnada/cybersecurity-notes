# Linux Basic Commands 🐧

## File Management

| Command | Description |
|---|---|
| pwd | Show current directory |
| ls | List files |
| cd | Change directory |
| mkdir | Create a directory |
| touch | Create a file |
| cat | Display file contents |
| cp | Copy files |
| mv | Move or rename files |
| rm | Remove files |
